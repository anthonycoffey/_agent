# Environment variables

Set in `agent/.env` (generated by Terraform on VM bootstrap). Loaded into containers via `docker compose`. Also auto-loaded into the SSH login shell.

## Stack-wide secrets

| Var | Used by | Notes |
|---|---|---|
| `POSTGRES_USER` | postgres, n8n, app workflows | Default: `agent` |
| `POSTGRES_PASSWORD` | postgres, n8n, app workflows | Generated by Terraform |
| `WEBUI_SECRET_KEY` | OpenWebUI, LiteLLM, n8n | The bearer token for LiteLLM. Single secret reused everywhere that needs to call the LLM proxy. |
| `N8N_ENCRYPTION_KEY` | n8n | **Critical.** Encrypts credentials in n8n's DB. Losing it = re-creating every credential. |
| `N8N_USER_MANAGEMENT_JWT_SECRET` | n8n | Session signing |
| `N8N_HOST` | n8n, cloudflared | Public hostname (`n8n.coffey.codes`) |
| `EVOLUTION_API_KEY` | Evolution (WhatsApp) | API key for the Evolution gateway |
| `TZ` | n8n cron, etc. | Timezone for scheduled triggers (`America/Chicago`) |

## n8n behavior

| Var | Value | Why |
|---|---|---|
| `N8N_RUNNERS_ENABLED` | `true` | Runners default-on in newer n8n; deprecated to set explicitly but harmless |
| `N8N_RUNNERS_MAX_OLD_SPACE_SIZE` | `1024` | 1GB heap for Code-node task runner |
| `N8N_RUNNERS_TASK_TIMEOUT` | `300` | 5min per task — needed for slow CPU-only Ollama calls |
| `N8N_BLOCK_ENV_ACCESS_IN_NODE` | `false` | Allow `$env` in expressions. Doesn't unblock Code-node `$env`/`process.env` though — those are sandboxed separately. |
| `NODE_FUNCTION_ALLOW_EXTERNAL` | `axios` | Lets Code nodes `require('axios')` |
| `N8N_COMMUNITY_PACKAGES_ALLOW_TOOL_USAGE` | `true` | Required for the langchain MCP Client Tool to plug into AI Agent nodes (the `ai_tool` connection slot is hidden without it). |

## MCP integrations

Tokens for the MCP server containers (see [`docker-compose.yml`](../../agent/docker-compose.yml) `mcp-*` services).

### Atlassian (Jira) — `mcp-atlassian` container

| Var | Used by | Notes |
|---|---|---|
| `ATLASSIAN_URL` | `mcp-atlassian` | Full URL of the Jira/Confluence instance (e.g. `https://ultrasoundai.atlassian.net`) |
| `ATLASSIAN_EMAIL` | `mcp-atlassian` | Email the API token is associated with |
| `ATLASSIAN_API_TOKEN` | `mcp-atlassian` | Created at id.atlassian.com → Manage Account → Security → API tokens. Read-only is enforced by the container's `READ_ONLY_MODE=true` + token scope. |

The Atlassian MCP authenticates clients via env-var only (single-tenant pattern). No n8n credential is involved; the workflow's MCP Client Tool node connects with `authentication: 'none'`.

### GitHub — `mcp-github` container

| Var | Used by | Notes |
|---|---|---|
| `GITHUB_TOKEN_MCP` | `mcp-github` (passed in as `GITHUB_PERSONAL_ACCESS_TOKEN`) | Fine-grained PAT with read-only scopes only: Contents/Pull requests/Issues/Metadata = Read. Used by the server to call the GitHub API per tool invocation. |

GitHub MCP requires a **per-request Bearer token at the MCP endpoint** (separate from the API token above). That bearer is configured via an n8n credential named `GitHub MCP - PAT` (httpBearerAuth type). The simplest setup uses the same PAT for both — set `GITHUB_TOKEN_MCP` in `.env` AND create the n8n credential with the same value.

### Notion — `mcp-notion` container

| Var | Used by | Notes |
|---|---|---|
| `NOTION_INTEGRATION_TOKEN` | `mcp-notion` (passed in as `NOTION_TOKEN`) | Notion internal-integration token created at notion.so/profile/integrations. Read-only behavior was enforced at the integration's Capabilities tab in v1; full-access enabled per [SPEC-MCP-003](../specs/archive/SPEC-MCP-003-notion-full-editing.md). |
| `NOTION_MCP_BEARER_TOKEN` | `mcp-notion` (passed in as `AUTH_TOKEN`) | Bearer token for the MCP server's HTTP transport. Authenticates n8n → MCP requests at `/mcp`. Generate with `openssl rand -hex 32`. |

Two-token model: the integration token authorizes server → Notion API; the bearer token authorizes n8n → MCP server. The bearer is stored in an n8n credential named `Notion MCP - Bearer` (httpBearerAuth).

## LiteLLM model routing

LiteLLM reads provider keys from its own env (passed through from `.env`):
- `ANTHROPIC_API_KEY`
- `OPENAI_API_KEY`
- `GOOGLE_API_KEY`

Plus its own master key via `LITELLM_MASTER_KEY` (which is set to the same `${WEBUI_SECRET_KEY}` value).

## Inside Code nodes

**Don't try to read env vars from a Code node.** Both `process.env` and `$env` are blocked. Use a credential on a native node instead. See [credentials](../architecture/credentials.md).
